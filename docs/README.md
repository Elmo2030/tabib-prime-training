# ملحقات الجزء الأول — ملفات `PDF`

الصفحة الرئيسية فيها قسم **ملحقات الجزء الأول** جاهز ومربوط بالملفين دول.

القسم ده **بيخفي نفسه لو الملف مش موجود** — يعني مفيش زائر حيدوس على رابط مكسور.
أول ما ترفع الملف بالاسم الصح، الكارت بتاعه بيظهر لوحده. **من غير أي تعديل في الكود.**

## الأسماء المطلوبة — بالظبط

| الملف | الكارت اللي بيظهر |
| :--- | :--- |
| `part1-appendix-01.pdf` | الملحق الأول |
| `part1-appendix-02.pdf` | الملحق الثاني |

الاسم لازم يكون **بالظبط** كده — حروف صغيرة، شرطة مش مسافة، وامتداد
`.pdf`.

## إزاي ترفع

من المتصفح مباشرة:

`github.com/Elmo2030/tabib-prime-training/upload/main/docs`

اسحب الملفين، وغيّر اسم كل واحد للاسم اللي في الجدول قبل ما تحفظ.

## عايز عناوين ووصف حقيقية؟

العناوين الظاهرة دلوقتي على الكروت **مؤقتة**. ابعتلي:

- عنوان كل ملحق
- سطر واحد يوصف اللي جواه

وأنا أحطّهم مكان المؤقت.

## ⚠️ قبل ما ترفع

- **ما ترفعش أي ملف فيه بيانات مريض** — الملفات دي بتتنشر على الإنترنت للعامة
- لو الملف فيه صور، اتأكد إنها من مصدر مفتوح أو عندك حق نشرها
- الحجم المعقول أقل من **10 ميجا** لكل ملف — الدكاترة بيفتحوا من الموبايل
