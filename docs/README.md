## إزاي القسم بيشتغل

كل كارت **بيتأكد إن ملفه موجود** قبل ما يظهر — عن طريق طلب
`HEAD`
خفيف ما بينزّلش الملف. لو الملف مش موجود، الكارت بيخفي نفسه، ولو الاتنين
ناقصين القسم كله بيختفي.

يعني: **مفيش زائر ممكن يدوس على رابط مكسور**، وأي ملف جديد بيظهر لوحده
أول ما يتحط بالاسم الصح.

- **ما ترفعش ملف فيه بيانات مريض** — الملفات دي منشورة للعامة على الإنترنت
- اتأكد إن أي صورة جوّه الملف من مصدر مفتوح أو عندك حق نشرها
